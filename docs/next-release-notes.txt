PZ Pulse Expanded - Workshop Release Notes

Released version: 1.5.1 (confirmed by the author on October 22, 2026)

The complete plain-text 1.5.1 entry is in
docs/steam-changelog.txt. This patch prevents a duplicate active moodle when
a supported direct integration and Moodle Framework expose the same
registration. Catch-all Framework moodles use an available matching browser
icon, with a text fallback when no icon is available.

Release validation:
- Source modversion and PZ Pulse extension version are 1.5.1.
- Browser renderer tests (36) and six Lua fixture files pass.
- The local development copy is synchronized by Scripts/toggle-pz-junction.ps1.
- The author reported that the in-game test passed and confirmed the 1.5.1 release.
